اصنع إضافتك بأي AI

  1. انسخ «البرومبت الاحترافي» بالزر تحت.
  2. الصقه في أي AI (Claude / ChatGPT / Gemini...) ثم اكتب فكرتك في آخره.
  3. خذ ملف HTML الناتج وأضفه من «مكتبتي» ثم «إضافة» — الفحص الفوري يؤكد سلامته.
  4. شغّلها من المكتبة، وإن أردت تحسينها اطلب من الـ AI «نسخة محدثة» وأعد تثبيتها (نفس id يحدّث القديمة).
بروتوكول التحسين التدريجي (مهم)
  1. جرّب اللعبة هنا وألعب جولة كاملة.
  2. اكتب ملاحظاتك بصدق: ما أعجبك؟ ما لم يعمل؟ ماذا تريد أن يتغير؟ (مثال: «اجعل السرعة أعلى، أضف مستويات، لون أجمل»)
  3. أرسل للـ AI: الملف الحالي + ملاحظاتك، واطلب تطبيق بروتوكول التعديلات الموجود في البرومبت.
  4. أعد تثبيت الملف الجديد — سيتم تحديث اللعبة نفسها مع بقاء إحصائياتك.

نصيحة: حسّن خطوة خطوة (لون → صعوبة → ميزة جديدة) بدل طلب كل شيء دفعة واحدة، فتحصل على جودة أعلى في كل مرة.

 الاتصال







الأونلاين يحتاج إنترنت. الأصدقاء يعملون عبر الخادم: طلب الصداقة يصل حتى لو الصديق غير متصل (ينتظره في الخادم)، وحالة الاتصال والدردشة والدعوات تمر عبر الخادم، والمايك وإرسال الألعاب واللعب الجماعي مباشرة بين الأجهزة وتُفتح تلقائيا حين يظهر الصديق متصلا. بلا إنترنت أو بلا خادم: استخدم «غرفة محلية بالكود» أدناه على نفس الشبكة.


 إعدادات متقدمة: خادم PeerJS مخصص وخادم TURN
TURN يساعد اللاعبين خلف شبكات صارمة (مثل شبكات الجوال) على الاتصال ببعض. المنصة تستخدم افتراضيا خادم relay عاما مجانيا قد يكون بطيئا أو محدودا؛ ضع خادمك هنا لأفضل ثبات.


 السيرفر العام
سيرفر مفتوح لأي لاعب في العالم، يتجهز تلقائيا في الخلفية بمجرد فتح الموقع فتدخله بضغطة واحدة. أنت مخفي تماما عن اللاعبين الآخرين حتى تضغط «دخول»، وتختفي فورا عند الخروج. بعد الدخول ترى المتصلين وتدردش معهم وتشارك الألعاب والإضافات والمظاهر وتحديثات المنصة بالدردشة، وتضيف من تحب كصديق، وتنضم للغرف المفتوحة. عند الدخول يظهر اسمك وعلمك وكودك للجميع، ويمكنك الخروج أو حظر أي لاعب في أي وقت.

 ربط حساب Google

لا يلزم رفع المنصة لأي خادم، لكن Google تشترط أن تُفتح المنصة عبر https:// أو http://localhost (لا يعمل من ملف file://)، وأن يكون لديك Client ID مجاني. تُحفظ النسخة الاحتياطية في مجلد مخفي خاص بالمنصة داخل Google Drive الخاص بك.









كيف أحصل على Client ID وأشغّلها محليا بدون رفع؟
  1. افتح console.cloud.google.com وأنشئ مشروعا، ثم فعّل Google Drive API.
  2. OAuth consent screen: اختر External وأضف حسابك في Test users.
  3. Credentials ثم Create OAuth client ID ثم Web application.
  4. في Authorized JavaScript origins أضف http://localhost:8000 (أو عنوان موقعك إن رفعتها لاحقا).
  5. للتشغيل محليا: افتح الطرفية في مجلد الملف ونفّذ python -m http.server 8000 ثم افتح http://localhost:8000/io-arena-hub-v4.html.
  6. الصق الـ Client ID هنا واضغط تسجيل الدخول.


 الربط السحابي (رابط JSON مخصص)
أدخل رابط تخزين JSON يقبل PUT وGET (مثل Firebase Realtime Database بصيغة https://اسم.firebaseio.com/io/user1.json?auth=...). يُرفع حسابك الحالي كاملا. الرابط سري ويُحفظ في هذا المتصفح فقط، ويجب أن يسمح الخادم بـ CORS.

شكل الملف وبطاقة التعريف
ملف HTML واحد مستقل، وفيه بطاقة تعريف JSON:
 multiplayer (للألعاب): كائن {min,max,mode} يُظهر زر « جماعي»، واللعبة تستخدم IO.mp للرسائل بين اللاعبين، والمنصة تدير الأصدقاء والغرف والاتصال.
 voice (للألعاب الجماعية): كائن {spatial, maxDistance, auto} يُظهر شارة المايك على اللعبة ويحدد الصوت المكاني ومسافة السماع وتشغيل المايك تلقائيا بعد إذن اللاعب. المايك والاتصال تديرهما المنصة عبر IO.voice.
 libs (للألعاب): مصفوفة بأسماء مكتبات محمّلة مثل ["three","three-fx","gsap"] تُحقن داخل اللعبة قبل كودها. تُنزَّل تلقائيا بالخلفية، وتظهر في تبويب «النظام».
 المظاهر المتقدمة: بجانب style يقبل المظهر مواصفة io-theme-ui (نصوص ولغة واتجاه ومواضع وأزرار جديدة بإجراءات، آمنة بالكامل) وكودا اختياريا io-theme-js يتطلب موافقة صريحة. زر «حزمة المظهر» يعطي الـ AI الهيكل وكل نصوص الواجهة.
الأيقونة icon: إيموجي، أو SVG مباشر يبدأ بـ svg، أو data:image صغير، أو link rel="icon" بـ data URI في head. للتعديل: priority (الأصغر أولا) وtargetVersion. للمظهر: palette. للعبة: palette تلوّن غلافها.
orientation: both طولي وعرضي، landscape عرضي فقط، portrait طولي فقط، وتنبّه المنصة اللاعب لتدوير جهازه تلقائيا. حماية المنصة: تُعرض أخطاء اللعبة في الشريط العلوي، ويُحاكى localStorage داخل الصندوق المعزول ويُحفظ عبر IO.

الدالةالوظيفة


IO.player.nameاسم اللاعب


IO.ready()تنبيه المنصة أن اللعبة جاهزة


IO.score(n)إرسال النتيجة (تُحفظ أفضل نتيجة تلقائياً)


IO.best()قراءة أفضل نتيجة محفوظة (رقم)


IO.save(k, v) / IO.load(k)حفظ/قراءة بيانات اللعبة (JSON — وload ترجع null إن لم توجد)


IO.models() / IO.model(id)معرّفات نماذج GLB التي أرفقها اللاعب للحقل models، ووعد يرجع ArrayBuffer للنموذج (أو null إن لم يُرفق) لتحميله بـ THREE.GLTFLoader.parse من مكتبة three-gltf


IO.player.country / IO.player.flagرمز بلد اللاعب (مثل SY) وصورة علمه (data URI) — فارغان إن أخفاهما اللاعب


IO.mp.players[i].cc / .flagبلد كل لاعب في الغرفة وعلمه


IO.voice.join() / leave()تشغيل/إيقاف الدردشة الصوتية لغرفة اللعبة (تطلب المنصة إذن اللاعب أول مرة)


IO.voice.mute(b) / toggle() / talk(b)كتم المايك، أو ضغط للتحدث (Push-to-talk)


IO.voice.spatial(true, {maxDistance, rolloff, plane})الصوت المكاني: يخفت صوت كل لاعب مع بعده ويأتي من جهته (plane: xz افتراضي، أو xy للألعاب ثنائية الأبعاد)


IO.voice.listener({x,y,z,fx,fy,fz}) / positions({id:{x,y,z}})موضعك واتجاهك ومواضع اللاعبين (المعرّفات من IO.mp.players)


IO.voice.channel(name) / volume(id,v) / on(fn)قناة فريق لا يسمع إلا من فيها، مستوى صوت لاعب (0 إلى 1.5)، ومتابعة الحالة (on, muted, speaking, peers)




القيود: بدون إنترنت أو ملفات خارجية، كل شيء داخل الملف. تعمل الإضافة في iframe معزول فلا تصل لبيانات المنصة مباشرة.


 صلاحيات الألعاب والمايك
الألعاب تعمل في صندوق معزول ولا تصل للمايك إلا عبر المنصة وبإذنك. اختر لكل لعبة: تسأل كل مرة، أو مسموح دائما، أو ممنوع. اللعبة المسموحة تحصل أيضا على إذن المايك المباشر من المتصفح (عند تشغيلها من جديد).




 مستوى أصوات اللاعبين




 مكتبات الألعاب (تُحمَّل بالخلفية)

تنزّل المنصة أشهر المكتبات (3D وتأثيرات وفيزياء وصوت وحركة) وتحفظها على جهازك، وتحقنها داخل أي لعبة تطلبها بالحقل libs بلا إنترنت لاحقا، وتضيفها تلقائيا إلى البرومبت. لا تُحسب ضمن حد الألعاب.








 مكتبة مخصصة


 التخزين والنسخ الاحتياطي









أرشيف ZIP يحوي ملفات الألعاب والتعديلات والمظاهر فقط (بدون الحسابات أو التقدم أو الأصدقاء أو الدردشات). يمكنك أيضا إسقاطه أو اختياره من «إضافة».


المكتبة تُخزَّن في قاعدة بيانات المتصفح (IndexedDB) بحد 50 ميجابايت للمنصة، وتطلب المنصة تخزينا دائما حتى لا يمسحها المتصفح. التصدير يحفظ كل الإضافات + المفضلة + الإحصائيات في ملف واحد. استورده على أي جهاز آخر.
